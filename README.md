# ContextMap

An interactive causal knowledge graph that maps the historical and topical context behind any event. Search for a Wikipedia-verified event (historical or current), and an AI generates a visual "yarn map" showing the chain of causes, consequences, and connections — with links to learn more about each one.

## How It Works

1. **Search** — Type any event, person, idea or place. Results come from Wikipedia's API, so every entry is a real, verifiable topic.
2. **Pick a scale** — Choose how far the map reaches, measured from the subject's own date (or from today for timeless subjects like a technology or a place):
   - **Immediate (~15 yr)** — the run-up and aftermath: specific people, decisions and incidents.
   - **Generational (~75 yr)** — movements, policies and technologies within living memory.
   - **Historical (~300 yr)** — institutions, ideologies and economic systems.
   - **Deep time** — origins and long-run roots, as far back as they go.

   The exact window (e.g. "1864 – 1989") is shown above the summary, and it is enforced in code, not just requested in the prompt: nodes outside it are discarded.
3. **Generate** — Select a result. The app sends the Wikipedia article to Google Gemini, which builds a map of specific, researchable nodes — causes, consequences, people, places, ideas, and parallel cases — each with a one-line hook and a link to a real Wikipedia article (links are checked, and dead ones removed). Changing the scale regenerates the map. Expect roughly 15–60 seconds (Deep time can take longer).
4. **Explore** — Nodes are colored by kind. Click one to highlight its connections and read how it links to its neighbours, or use the "All nodes" list in the sidebar. Each node is meant as an entry point for further research.

### Example: 1939 Chillán Earthquake

The app opens on a built-in example (generated by ContextMap itself at Generational scale): the 1939 earthquake, the 1928 quake that produced Chile's first seismic building code, the creation of CORFO, and a U.S. bomber's relief flight. Search for something else, or switch the scale to Historical or Deep time to watch the Spanish conquest of Chile enter the picture.


## Getting Started

### Quick Start (pre-built release)

If you downloaded a release `.zip`, **no build tools are needed** — just Node.js:

1. **Install [Node.js](https://nodejs.org/)** (v18 or later). Verify with `node -v` in a terminal.
2. **Unzip** the release folder anywhere.
3. **Add your API key** — copy `.env.example` to `.env` and paste your free [Google Gemini API key](https://aistudio.google.com/apikey):
   ```
   GEMINI_API_KEY=your_key_here
   ```
4. **Double-click `ContextMap.bat`** — the app opens in your browser at http://localhost:3001.

That's it. No `npm install`, no build step.

### From Source (development)

#### Prerequisites

| Requirement | Version | How to get it |
|---|---|---|
| **Node.js** | 18+ | [nodejs.org](https://nodejs.org/) — use the LTS installer. This also installs `npm`. |
| **npm** | 9+ | Comes with Node.js. Verify: `npm -v` |
| **Gemini API key** | — | Free, no credit card: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

#### Installation

```bash
# Clone the repo
git clone https://github.com/SRP1612/ContextMap.git
cd ContextMap

# Install dependencies
npm install

# Set up your API key
cp .env.example .env
# Edit .env and paste your Gemini API key
```

> **Windows note:** If `cp` doesn't work, just copy `.env.example`, rename the copy to `.env`, and edit it.

#### Running

**Option A — Production mode (one command):**

```bash
npm run build
npm start
```

Then open http://localhost:3001. Or double-click `ContextMap.bat`.

**Option B — Development mode (hot reload):**

```bash
# Terminal 1: API server
npm run dev:server

# Terminal 2: Vite dev server with hot reload
npm run dev
```

Then open http://localhost:5173.

#### Building a Release

To produce a self-contained folder you can zip and share:

```bash
npm run build:release
```

This creates `release/ContextMap/` containing everything needed to run — recipients only need Node.js and their own API key.

## Tech Stack

- **Frontend:** React 19, TypeScript, [React Flow](https://reactflow.dev/), [Dagre](https://github.com/dagrejs/dagre) (graph layout), Tailwind CSS
- **Backend:** Express 5 (serves both API and built frontend)
- **AI:** Google Gemini Flash models (free tier), with a configurable fallback chain — see [Free-tier limits](#free-tier-limits)
- **Data Source:** Wikipedia API (ensures verifiable, factual input)
- **Resilience:** Falls back across models on overload or exhausted quota; short rate limits show a countdown and auto-retry, daily limits show a clear message

## Configuration

| Variable | Description |
|---|---|
| `GEMINI_API_KEY` | Your Google Gemini API key ([get one free](https://aistudio.google.com/apikey)) |
| `GEMINI_MODEL` | Optional. Comma-separated Gemini models to try in order (default: `gemini-3.8-flash,gemini-3.7-flash,gemini-3.6-flash,gemini-3-flash-preview,gemini-3.5-flash-lite`). See the [model list](https://ai.google.dev/gemini-api/docs/models). |
| `GEMINI_CLASSIFY_MODEL` | Optional. Cheap models tried first for the small "what kind of subject is this?" call (default: `gemini-3.5-flash-lite,gemini-3.1-flash-lite`). |
| `PORT` | Server port (default: `3001`) |

## Free-tier limits

Free Gemini keys work, but they are tight, and Google changes them often:

- Each model allows only about **20 requests per day** on the free tier (this was observed on `gemini-2.5-flash`; check your own limits in [AI Studio](https://aistudio.google.com/rate-limit)). A search uses one request on the main model plus one small classification request, so ContextMap tries a chain of models and skips any that are out of quota. That gives roughly dozens of searches a day.
- The newest models return temporary "high demand" (503) errors for a share of requests; ContextMap hops to the next model instead of waiting.
- Free-tier prompts may be used by Google to improve its products. Only public Wikipedia text is sent, but keep it in mind.
- Model names change. If you see "no longer available" errors, update `GEMINI_MODEL` in `.env`.

## Security Notes

- **API keys are never committed.** The `.env` file is in `.gitignore`. Only `.env.example` (with placeholder values) is tracked.
- **The server only listens on `127.0.0.1`** and sends no CORS headers, so other machines on your network and other websites in your browser cannot use your API key.
- **User input is restricted** to Wikipedia entity search — users cannot inject free-form prompts into the AI.
